# Mobius 구현 잔여 작업 계획

외부 플랫폼 공식 API Connector는 현재 범위에서 제외한다. Google OAuth·이메일은 키 없이도 설정·시뮬레이션·재시도까지 구현하고, 실제 발송/로그인은 키 입력 후 활성화한다.

## P0 — 대시보드 기능 완성 ✅ 완료

- 공격 유형별 멀티라벨 점수와 모델 출처 표시
- 이미지 업로드, OCR 결과, 이미지 지문·유사 이미지 탐지 결과 표시
- 계정·대상·해시태그 그래프 시각화
- 클러스터, 협조 행동 점수, 연결 계정 드릴다운
- 알림 이력·알림 설정·증거 패키지 다운로드 상태 표시
- 피해자 보호/B2B 역할별 화면·메뉴 분리

완료 기준: 웹만으로 위험 근거, 공격 유형, 그래프, 증거, 대응 가이드, 알림 이력을 모두 탐색할 수 있다.

완료 검증: 최신 Docker API에서 이진·멀티라벨 모델, OCR·그래프, RBAC 알림, PostgreSQL 알림 이력, 증거 ZIP 흐름을 통합 검증했다.

## P1 — 데이터 영속화·멀티테넌트 보안 ✅ 완료

- PostgreSQL 테이블: 조직, 사용자, 역할, 분석 대상, 이벤트, 증거 패키지, 알림, 감사 로그
- 조직별 tenant ID 격리와 대상·증거 접근 권한 적용
- 증거 패키지 생성 이력, SHA-256, 다운로드 감사 로그 저장
- 원문/마스킹본 분리, 보존 기간·삭제 처리 정책 구현

완료 기준: 재기동 뒤에도 분석·알림·증거 이력이 유지되고, 다른 조직 데이터에 접근할 수 없다.

완료 검증: PostgreSQL에 조직·사용자·역할·대상·이벤트·테넌트 알림·증거·감사 테이블을 생성했다. 피해자/B2B의 전용 대상 목록을 분리하고 교차 대상 요청은 404로 차단했으며, 증거 ZIP 다운로드(200), SHA-256 이력, 다운로드 감사 로그, 재기동 후 조직별 알림 이력을 Docker API에서 검증했다. 원문은 기본 미저장, 마스킹 데이터 보존 기간은 90일 정책으로 설정했다.

## P2 — 인증·알림 운영화 ✅ 완료

- OAuth/OIDC 로그인 플로우와 세션/JWT 처리
- Google 설정값(Client ID, Client Secret, Redirect URI) 주입 방식
- SMTP 또는 메일 서비스 발송·실패 재시도·이력 저장
- 위험 단계 전환·알림 빈도 제한·묶음 알림 정책

완료 기준: 키 미설정 시 시뮬레이션으로, 키 설정 시 실제 로그인·발송으로 동일 인터페이스가 동작한다.

완료 검증: 데모 로그인에서 1시간 JWT를 발급하고 Bearer 세션으로 권한·테넌트를 확인했다. Google은 Client ID·Secret·Redirect URI 주입 시 OAuth 인가·콜백을 수행하며, 초대된 이메일만 역할을 부여하도록 구현했다. SMTP는 3회 재시도하고 키 미설정 시 시뮬레이션 이력을 저장한다. 30분 동일 위험 단계 쿨다운·묶음 처리를 확인했으며, 별도 테스트 프로세스에서 실제 이메일 알림 저장 분기를 실행해 PostgreSQL 발송 이력을 검증했다.

## P3 — 그래프·멀티모달 분석 고도화 ✅ 완료

- Neo4j 연동 및 temporal graph 증분 저장
- 클러스터·중심성·반복 문구·플랫폼 간 동시성 기반 협조 행동 점수
- 이미지 perceptual hash/임베딩 유사도 검색 인덱스
- OCR 텍스트를 이진·멀티라벨 분류 파이프라인에 합산
- 영상 프레임·STT는 별도 확장 모듈로 설계·시뮬레이션

완료 기준: 동일 밈·해시태그·계정군의 확산 경로와 협조 행동 신호를 근거와 함께 시각화한다.

완료 검증: Docker Neo4j에 계정·대상·해시태그 노드와 관계를 증분 저장하고 그래프 API에서 `neo4j_incremental` 상태를 확인했다. 중심성, 반복 문구 점수, 15분 플랫폼 동시성 지표를 반환한다. 이미지 perceptual hash를 조직별 PostgreSQL 인덱스에 저장해 유사 이미지를 비교하고 OCR 텍스트의 공격 유형을 분석한다. 영상은 frame sampling·OCR·STT·텍스트 분류 확장 계약을 시뮬레이션 API로 제공한다.

## P4 — 품질 검증·발표 준비 ✅ 완료

- 이진·멀티라벨 모델의 데이터셋별/클래스별 평가 리포트
- 시간 누수 없는 백테스트와 조기경보 리드타임 시각화
- API·DB·OCR·그래프·웹 E2E 테스트
- synthetic replay 발표 시나리오 및 개인정보·윤리 고지
- 운영/보안·한계·fallback 정책 문서화

완료 기준: 링크 하나로 시연 가능하고, 평가 수치·근거·데모 데이터 고지·제한 사항을 발표 자료에 제시할 수 있다.

완료 검증: `EVALUATION.md`에 이진 F1 0.7928, 멀티라벨 Micro/Macro F1 0.7852/0.6860과 데이터·한계를 정리했다. 시간순 synthetic replay를 재실행해 Brier 0.1641, Precision 0.6667, Recall 1.0, 리드타임 5분을 확인했다. `DEMO_SCRIPT.md`, `OPERATIONS.md`, `scripts/verify_p4.ps1`을 추가했고, 웹 프로덕션 빌드 및 Docker API·PostgreSQL·Redis·Neo4j 통합 시나리오를 통과했다.

## P5 — 최종 Docker 통합·배포 검증 ✅ 완료

- 모든 변경사항을 포함한 최신 Docker 이미지 빌드·컨테이너 재기동
- PostgreSQL 알림·증거·조직 이력 영속화 검증
- 이진·멀티라벨·OCR·그래프·RBAC·알림·웹의 E2E 시나리오 실행
- 헬스체크, 에러 로그, 모델 로드 상태, 증거 ZIP 다운로드 확인

완료 기준: Docker 환경에서 전체 기능이 하나의 시나리오로 정상 동작하고, 외부 키 미설정 기능은 시뮬레이션 상태를 명확히 반환한다.

완료 검증: 웹 프로덕션 빌드 후 API 이미지를 재빌드하고 PostgreSQL·Redis·Neo4j·API 컨테이너를 전체 재생성했다. `scripts/verify_p5.ps1`에서 health `ok`, 이진 모델 `ready`, 멀티라벨 모델 `kmhas_multilabel_v1`, 그래프 `neo4j_incremental`, 증거 ZIP HTTP `200`(3.5KB 이상), 조직별 알림·이메일 이력을 확인했다. 모든 컨테이너는 현재 실행 중이다.

## 사용자님이 제공해야 하는 외부 설정

- OAuth 공급자 Client ID/Secret 및 Redirect URI
- SMTP 또는 메일 발송 서비스 키

위 항목 없이도 나머지 구현·시뮬레이션·통합 검증은 진행 가능하다.
