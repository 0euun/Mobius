# 운영·보안·한계 정책

## 데이터와 개인정보

- 공식 API·고객 제공·허가된 공개 데이터만 수집 대상이다.
- 원문은 기본 미저장, 마스킹 데이터 기본 보존 기간은 90일이다.
- 증거 패키지는 해시·생성 이력·다운로드 감사 로그를 남긴다.
- 삭제 요청과 보존 기간 만료는 운영자가 검토한 뒤 처리한다.

## 보안

- 조직·대상·알림·증거는 tenant ID로 분리한다.
- 역할은 Google 로그인 공급자가 아닌 Mobius DB의 초대·승인 정보로 결정한다.
- `.env`와 OAuth/SMTP 비밀값은 저장소·발표 화면에 포함하지 않는다.
- 운영 배포에서는 기본 JWT 시크릿을 반드시 랜덤 값으로 교체하고 HTTPS만 사용한다.

## Fallback·한계

- 모델/OCR/Neo4j가 일시적으로 실패하면 API는 오류 원인 또는 제한된 fallback 상태를 반환한다.
- 협조 행동·유해성 점수는 자동 제재 근거가 아니며, 인적 검토와 이의제기 절차가 필요하다.
- 영상 STT는 확장 계약만 구현됐으며 실제 처리 전 명시적 동의·보존 정책·별도 워커가 필요하다.
