# 학습 데이터 출처 및 사용 기록

원본 데이터는 `data/raw/`에 분리 보관하며 Git에 커밋하지 않는다. 처리 결과도 `data/processed/`에 두고 Git에서 제외한다. 학습·발표물에는 아래 출처를 인용한다.

| 데이터셋 | 원본 저장소 | 용도 | 주의 사항 |
|---|---|---|---|
| KOLD | https://github.com/boychaboy/KOLD | 공격성 발화 이진 분류·대상 속성 보조 학습 | 저장소의 악성 언어 생성·배포 목적 사용 금지 고지를 준수한다. 명시 라이선스는 별도 재확인한다. |
| BEEP! Korean HateSpeech | https://github.com/kocohub/korean-hate-speech | 혐오·공격성·성별 편향 분류 학습 | 원본 `LICENSE.md` 및 인용 안내를 보존한다. 레이블 없는 테스트 파일은 학습에 사용하지 않는다. |
| K-MHaS | https://github.com/adlnlp/K-MHaS | 8개 세부 혐오표현 멀티라벨 학습·평가 | 원본 저장소의 논문 인용 요구를 따른다. 실제 서비스 배포 전 라이선스·개인정보 적합성을 별도 검토한다. |

모든 데이터는 유해 표현을 포함할 수 있다. 원문을 대시보드·로그·발표 화면에 그대로 노출하지 않으며, 접근 권한과 보존 기간을 제한한다.
